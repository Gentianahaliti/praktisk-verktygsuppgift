# Repository-samarbete 
Ett repository gör att flera personer kan arbeta i samma projekt utan att skriva över varandras arbete.
Man använder commit, push och pull för att samordna ändringar.
Detta kan man göra:
arbeta i samma projekt
spara ändringar med commit - uppdaterar gemensamt arbete 
hämta ändringar med pull
skicka ändringar med push
arbeta separat med branches – då jobbar man med egna versioner och påverkar inte den gemensamma versionen. När man är klar går man igenom innehållet och lägger ihop det genom en merge till en enda version.
