Jag använde pwd för att se vilken mapp jag var i och ls för att se vad som fanns där.

Med cd kunde jag gå till en annan mapp.

Jag använde mkdir för att skapa en ny mapp.

Sen skapade jag min README‑fil direkt från terminalen med echo

Jag använde git init för att starta Git.

Git status visade vilka ändringar som fanns.

Med git add valde jag vilka ändringar som skulle sparas.

Med git commit sparade jag ändringarna.

Med git remote add origin kopplade jag arbetet till mitt Github.

Till sist använde jag git push -u origin main för att skicka arbetet till GitHub.

Och varje gång jag gjorde en ny uppdatering så använde jag t.ex. git add "mina-bash-kommandon.txt", git commit -m "uppdaterade bash-kommandon"
sist git push som skickade mina sparade ändringar från datorn till Github.

Jag råkade radera all text jag hade skrivit, så jag använde git restore mina-bash-kommandon.txt för att få tillbaka den.
