Jag använde pwd för att se vilken mapp jag var i och ls för att se vad som fanns där. 

Med cd kunde jag gå till en annan mapp. 

Jag använde mkdir för att skapa en ny mapp och touch för att skapa en fil. 

Med cat kunde jag se innehållet i en fil.

Sedan använde jag git init för att starta Git i projektet. 

Git status visade vilka ändringar som fanns. Med git add gjorde jag ändringar.

Med git commit sparade jag ändringarna.

Efter det använde jag git branch -M main för att kalla huvudbranchen main.

Med git remote add origin kopplade jag projektet till mitt GitHub-repository. 

Till sist använde jag git push -u origin main för att skicka projektet till GitHub
